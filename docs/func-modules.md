# 功能模块(页面新建真实步骤模块)

## 是什么

DAG 由模块/节点组合;系统内置四类生命周期编排(create/destroy/scaleout/backup),
页面上的“自定义草稿”只能填节点名(Noop 示意)。**功能模块**让用户直接在页面定义
一段**真实、可执行、可复用**的步骤序列,例如“执行一段 SQL / 容器内跑命令 / 写配置 /
等待 MySQL 就绪 / 移除容器”,保存后随时对任意运行中实例**一键运行**。

- 入口:侧栏「任务」→ 任务编排页签 → **功能模块**(tab,与 节点组目录/新建编排 并列);
- 权限:`tasks.view` 只读;`tasks.manage` 可新建/编辑/复制/删除/运行;
- 模块 = 单个任务节点,步骤顺序执行;步骤类型与系统 DAG `Step` 完全一致(JSON)。

## 编辑与保存

页面上:
1. 「+ 新建功能模块」:填 模块名/分类/说明;
2. 添加步骤行:选择类型(执行 SQL / 容器内命令 / 写配置/文件 / 等待 MySQL 就绪 /
   移除容器 / 说明占位),下方 JSON 即该步骤参数,可自行调整(高级可整段改 JSON);
3. 保存 → 同名模块**覆盖更新**(相当于版本迭代)。

占位符(运行时按目标实例替换):
- `{instance}` → 目标实例名;
- `{master}` → 目标实例主节点容器名。

## 运行语义

「运行」选择目标实例(需 running)→ 后端把模块步骤实例化后提交为一个
`module` 任务:

- 与 backup 同类:**加实例短租锁、终态解锁;失败不修改实例状态**,仅告警留痕
  (可在任务中心展开失败节点重试单步);
- 审计记录 `module_run`,任务 kind=功能模块,节点名“执行模块:{模块名}”;
- 历史任务已物化为节点快照:模块后续被删/改名不影响已执行任务。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/rds/modules` | 模块列表 |
| POST | `/api/rds/module?name=&category=&desc=&steps=<Step数组JSON>` | 新建/同名覆盖 |
| POST | `/api/rds/module/delete?name=` | 删除 |
| POST | `/api/rds/module/run?name=&instance=` | 一键运行 |

步骤为 serde 外部标签 JSON,示例:
```json
[
  {"ExecSql": {"container": "{instance}", "user": "root", "pass": "rds_root_2024", "sql": "SELECT 1"}},
  {"Noop": {"note": "说明步骤"}}
]
```

## 边界

- v0 模块 = 单节点步骤序列;多节点 DAG 模块与“插入新建编排向导组合链”为后续迭代;
- 危险动作(移除容器/任意命令)由使用者负责;删除类操作页面二次确认;
- 运行需目标实例 running(与生命周期任务同样的前置门槛)。
